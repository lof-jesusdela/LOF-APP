# LOF · La Obra Fitness

App de acompañamiento para alumnos de Jesús de la Obra. Funciona en el navegador del móvil y se instala en la pantalla de inicio.

Este repositorio solo contiene la app. Ningún dato de alumnos se guarda aquí: viven en Supabase, protegidos por reglas de privacidad que solo permiten a cada alumno ver lo suyo.
